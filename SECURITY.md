# Security policy

## Supported versions

This is an experimental application. Security fixes are applied only to the latest revision of `main`; tagged releases are not currently maintained.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed secret. Use GitHub's private vulnerability reporting flow:

https://github.com/senneco/udf-sandbox/security/advisories/new

Include reproduction steps, affected revisions, impact, and a proposed mitigation when possible. Remove unrelated personal or secret data from the report.
